# TorrPlayer

Лёгкий внешний видеоплеер для Android TV / приставок, который **выбирается как плеер
внутри Lampa** (как MX Player или VLC), а не работает как отдельный каталог торрентов —
это уже делает Lampa + TorrServer.

## Как это работает
1. В Lampa вы, как обычно, находите фильм/сериал через TorrServer.
2. Lampa запускает выбранный плеер стандартным Android-интентом `ACTION_VIEW`
   с прямой ссылкой на поток TorrServer (`http://host:port/stream/...?link=hash&index=N&play`).
3. TorrPlayer подхватывает эту ссылку (за счёт `intent-filter` в манифесте — поэтому
   он и появляется в системном списке "выбрать плеер"), сам вытаскивает из неё
   хост TorrServer и хеш торрента и играет поток через Media3 ExoPlayer.
4. Никакой ручной настройки адреса TorrServer для воспроизведения не требуется.

## Возможности
- Media3 ExoPlayer: mp4, mkv/webm, ts/m2ts, avi, mov, ogg, wav, flac, HLS, DASH, RTSP
  — кодеки ограничены только декодерами самой приставки.
- Поддержка сложного звука (AC-3/DTS/TrueHD и т.п.) через программный FFmpeg-декодер
  (`org.jellyfin.media3:media3-ffmpeg-decoder`) — с принудительным декодированием в PCM
  для ТВ без eARC (переключается в настройках, см. ниже).
- D-pad управление на пульте: удержание влево/вправо — ускоряющаяся перемотка
  в 3 стадии, настраиваемый базовый шаг (1–60 сек).
- Индикатор буфера (% буферизации от плеера) + скорость закачки/пиры от TorrServer.
- Выбор аудиодорожки и субтитров, регулировка скорости воспроизведения, смена
  режима растяжения кадра.
- Продолжение просмотра с места остановки.
- Список серий торрента с автоматической натуральной сортировкой по номеру
  («Серия 2» идёт перед «Серия 10», а не наоборот) и **автопереходом на следующую
  серию** по окончании текущей (можно отключить в настройках).
- Самообновление: экран настроек проверяет последний релиз на GitHub и ставит
  обновление без стороннего маркета.

## Настройки (SettingsActivity)
- Адрес TorrServer — используется только для кнопки "Проверить соединение",
  для самого воспроизведения не требуется (адрес плеер берёт из ссылки от Lampa).
- Шаг перемотки.
- Показывать индикатор буфера.
- Продолжать с места остановки.
- Автоматически включать следующую серию.
- Всегда декодировать сложный звук в PCM (вкл. по умолчанию — для ТВ без eARC).
- Проверить обновления.

## Сборка и подпись
GitHub Actions (`.github/workflows/build-apk.yml`) собирает **release-APK** при пуше
в `main` и публикует его в Releases репозитория. APK подписывается фиксированным
release-ключом, хранящимся в GitHub Secrets (`KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`,
`KEY_ALIAS`, `KEY_PASSWORD`) — это гарантирует, что сертификат не меняется между
сборками, и встроенный самообновлятор может ставить новые версии поверх старых
без переустановки.

## Известные ограничения
- Формат ответа TorrServer на `action=get` может отличаться между версиями — сам
  индикатор буфера (по данным ExoPlayer) работает всегда, скорость/пиры — best effort.
- Внешние субтитры поддерживаются только те, что явно передаёт вызывающий плеер
  через intent-extras (`subs`/`subs.name`); субтитры, отдаваемые самим TorrServer
  отдельным файлом, пока не подхватываются автоматически.
