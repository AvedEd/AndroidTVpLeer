# TorrPlayer

Лёгкий внешний видеоплеер для Android TV / приставок, который **выбирается как плеер
внутри Lampa** (как MX Player или VLC), а не работает как отдельный каталог торрентов —
это уже делает Lampa + TorrServer.

## Как это работает
1. В Lampa вы, как обычно, находите фильм/сериал через TorrServer.
2. Lampa запускает выбранный плеер стандартным Android-интентом `ACTION_VIEW`
   с прямой ссылкой на поток TorrServer (`http://host:port/stream/...?link=hash&index=N&play`).
3. TorrPlayer подхватывает эту ссылку (за счёт `intent-filter` в манифесте — поэтому
   он и появляется в системном списке "выбрать плеер"), сам вытаскивает из неё
   хост TorrServer и хеш торрента и играет поток через Media3 ExoPlayer.
4. Никакой ручной настройки адреса TorrServer для воспроизведения не требуется.

## Возможности
- Media3 ExoPlayer: mp4, mkv/webm, ts/m2ts, avi, mov, ogg, wav, flac, HLS, DASH, RTSP
  — кодеки ограничены только декодерами самой приставки.
- Настраиваемый шаг перемотки (5/10/15/30/60 сек).
- Индикатор буфера (% буферизации от плеера) + скорость закачки/пиры от TorrServer.
- Выбор аудиодорожки и субтитров, регулировка скорости воспроизведения.
- Продолжение просмотра с места остановки.

## Сборка
GitHub Actions (`.github/workflows/build-apk.yml`) собирает debug-APK при пуше в `main`
и публикует его в Releases репозитория.

## Известные ограничения
- DTS / TrueHD аудио могут не воспроизводиться без отдельного FFmpeg-расширения Media3
  (требует сборки нативного кода через NDK — не включено в проект).
- Формат ответа TorrServer на `action=get` может отличаться между версиями — сам
  индикатор буфера (по данным ExoPlayer) работает всегда, скорость/пиры — best effort.
